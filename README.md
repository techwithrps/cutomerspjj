# SPJ Group of Companies — Customer Invoicing & Cargo Gateway

Dedicated Enterprise Customer Portal for SPJ Logistics & Multimodal Transport clients (e.g. HMA Agro Industries Ltd, Allana Sons, ITC Limited, LG Electronics).

## 🚀 Key Features

- **🔐 Authenticated Client Login**: Role-scoped customer authentication with demo auto-fill for testing.
- **📄 Invoices in Modern Cards Format**:
  - Full tax breakdown (Taxable Amount + CGST + SGST).
  - Associated Job Orders, Booking Numbers, Shipping Lines & Ports.
  - Interactive Filter by Status (Paid, Pending, Processing) & real-time search.
  - Itemized Tax Invoice Statement Modal with print & download support.
- **📦 Live Container & Yard Tracking**:
  - Reefer temperature tracking (-18°C frozen cold chain), seal numbers, gate-in/gate-out logs, and live train GPS locations.
- **🏢 Company Profile & GST Details**:
  - Statutory details (GSTIN, IEC, PAN, Registered Address).
  - Credit line status and dedicated SPJ Relationship Manager desk.
- **📱 Seamless Mobile & Web Responsive Design**:
  - Mobile bottom drawers, high-density touch cards, and clean viewport layouts.

---

## 💻 Tech Stack

- **Frontend**: React 18, Vite 5, Tailwind CSS
- **Icons**: Lucide React
- **Design System**: Plus Jakarta Sans & Outfit fonts, Rich HSL palettes
